=====================
Scenarios KirmansAnts
=====================

Default scenarios provided out of the box:

- Scenario.0 (baseline): bimodal — :math:`\rho = 0.5,\, \mu = 1.0` (no shocks).
- Scenario.1: Uniform — :math:`\rho = 1.0` via ``rho_add = +0.5``.
- Scenario.2: Unimodal — :math:`\rho = 2.0` via ``rho_add = +1.5``.

All scenarios are implemented in
``macrostat.models.KirmansAnts.scenarios.ScenariosKirmansAnts``.
